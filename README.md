# QPSK Digital Communication System

This project demonstrates Quadrature Phase Shift Keying (QPSK), a digital modulation technique that transmits two bits per symbol using four phase states. It improves bandwidth efficiency and is widely used in wireless and satellite communication systems.

## Features
- QPSK-based digital modulation  
- Two-bit symbol transmission  
- Improved bandwidth efficiency  
- Simulation of modern communication systems  

## Hardware Required
- Arduino board  
- Speaker or buzzer  
- Basic signal output circuit  

## Applications
- Wireless communication  
- Satellite systems  
- Digital RF communication
